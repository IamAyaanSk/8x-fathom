The Google client ID/secret were fine. The failure was **module load order**: `@repo/db` was imported before `loadEnvFile()` ran, so Prisma started **without** `DATABASE_URL`. It hit the wrong database (no `verification` table), and Better Auth returned **500** on `sign-in/social`.

### Fix applied

1. **`server.ts`** — `import '#src/env'` as the first import.
2. **`auth.ts`** — import `env` before `prisma` from `@repo/db`.
3. **`users.ts`** — same env preload before Prisma.
4. **`packages/database/src/client.ts`** — throw a clear error if `DATABASE_URL` is missing at import time.

After a server restart, `POST /api/auth/sign-in/social` returns **200** with a Google OAuth URL.

### What you should do

1. Restart dev (`turbo run dev` or restart the server package).
2. Try **Continue with Google** again.

- Redirect URI: `http://localhost:5173/api/auth/callback/google`
