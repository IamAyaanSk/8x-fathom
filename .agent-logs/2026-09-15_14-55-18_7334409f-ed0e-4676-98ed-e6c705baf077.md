Capture timing is fixed end-to-end so the UI and API agree.

### Behavior

| When | Capture button |
|------|----------------|
| **More than 2 min before** scheduled start | **Enabled** — for hosts who start the call early |
| **Within 2 min before** start (until start) | **Disabled** — tooltip: *“The bot will be joining the meet soon.”* |
| **After** scheduled start (no bot yet) | **Enabled** — fallback if auto-dispatch did not run |
| Bot already dispatched | Disabled — *“Capture started”* |
