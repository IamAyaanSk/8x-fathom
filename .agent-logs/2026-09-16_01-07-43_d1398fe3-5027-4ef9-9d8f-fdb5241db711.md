Here’s what was going wrong and what we changed:

### Causes
1. **Every debounced save** called `invalidateQueries` on meeting detail → full refetch every ~800ms–2s → parent re-rendered and effects fought local state.
2. **Scratchpad** synced from server on every `elapsedSec` tick and on `entryAtCurrentTime?.text` changes → draft reset mid-typing; debounce used stale trimmed text from schedule time.
3. **Highlight** used one mutation for title saves and “End” → `isPending` made the **End** button (and sometimes **Highlight**) spin during background title PATCHes.
4. **Title effect** re-ran on `activeHighlight.note` updates from the server and overwrote what you were typing.

### Fixes
- **Mutations** now **patch the React Query cache** for highlight/scratchpad saves instead of invalidating (no refetch storm).
- **Scratchpad**: `isDirty` + refs; only load from server when the second changes and you’re not editing; read **latest text from a ref** when the debounce fires; removed the “Saving…” spinner tied to every request.
- **Highlight**: sync title only when **highlight id** changes (guard with `syncedHighlightIdRef`); **End** spinner only when `endTimestampSec` is in the mutation; title debounce uses a ref.

After a refresh, typing should feel stable, saves should wait for the debounce, and spinners should only show for start/end highlight actions.
