**Changes:**

1. **`apps/web/src/lib/upcoming-meeting-capture.ts`** — For `failed_to_join`, `canCapture` no longer requires `isManualCaptureAllowed`. Retry stays allowed until `endTime` (still blocked for `failed_processing` or while a request is in flight).

First-time **Capture** (no bot yet) is still disabled in that window so it doesn’t fight the worker scheduler. Only **Try again** after a failed join is enabled while the meeting is still upcoming.
